# 土豆法语
## 📖 项目简介

这是一个专为法语初学者设计的**听力训练工具**，共包含86 篇听力材料，
分为日常、旅行、餐饮、购物、工作、健康、娱乐、自然、情感9个主题。

## ✨ 核心功能

### 🎧 听力练习（核心模块）
- **86 篇听力资源**
- **三种练习模式**：
  - 每次练习前，先浏览跟读**单词列表**（三种模式开始前都会弹出）
  - 📝 **选择题** — 快速检测理解能力
  - ⌨️ **逐句听写** — 精听训练，逐句还原
  - 📄 **全文听写** — 综合听力与拼写能力
- **📕 智能错题本**：
  - 逐句听写和全文听写中的错题**自动收录**
  - 可在错题本中**针对性反复练习**

### 🗣️ 口语知识（辅助模块）
- 音素、字母组合与发音规则
- 音素对应的嘴型图示
- 词尾发音规则（发音/不发音）
- 联诵规则

> ⚠️ **注意**：口语部分的发音示范调用了浏览器内置 TTS（文本转语音）引擎，单词的发音是对的，**音标的发音不准确**，

1. 推荐**使用电脑**，若使用手机和平板，需要自行安装google的发音语音包，
否则会调用手机自带的法语语音包（有缺陷），只能练习选择题和全文听写，
